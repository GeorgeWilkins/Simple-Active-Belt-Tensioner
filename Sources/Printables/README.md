# FreeCAD Source Files

If you're here looking for things to print, _you're in the wrong place_; go [here](/Printables) instead.

These files are the original [FreeCAD](https://www.freecad.org/) design files from which the printable `.STEP` files are generated. You'll only need these if you intend to change the designs of the parts.

Documenting the customisation of these files is beyond the scope of this project. If you need help with FreeCAD, please refer to the official [FreeCAD documentation](https://wiki.freecad.org) or community resources.
