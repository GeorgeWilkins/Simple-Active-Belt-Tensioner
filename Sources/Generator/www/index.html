Motor Bracket for Aluminium Profile

This is the bracket that attaches each tensioner motor to your aluminium profile. You'll need to print two of these.

The design can be customised to be mounted to the face or edge/corner of your aluminium profile. In both cases it requires two T-slots to bolt onto; either on the same or perpendicular faces.

Once you've entered and submitted the appropriate values, a .STEP file will be downloaded. This can be used in most 3D printer slicer software.

Source File: Motor Brackets/For Aluminium Profile (Parametric).FCStd

Leg Angle (90~180°)

This bracket supports two types of mounting. Use 90° for edge/corner mounting and 180° for face mounting. Alternatively use any angle within that range for more unusual rig frames with angled profile

Leg Width (>=30mm)

How wide each bracket leg should be. For either mounting type, this would typically be equal to your Hole Spacing value. For edge/corner mounting this may be equal to the total width or depth of your profile

Clearance Height (50~200mm)

How far from the profile the cord should exit the motor pulley. This must be at least 50mm for motor drum clearance; higher values will create weaker brackets unless Leg Width is also increased (and even then, maximum height is limited)

Hole Diameter (6~10mm)

The size of the bolt holes for mounting (typically 8mm for M8). A modest 0.2mm clearance is automatically added when generating the holes, so you don't need to include that in the value you provide

Hole Spacing (>=30mm)

The centre-to-centre distance between the mounting holes. For face mounting this is usually the slot spacing of your aluminium profile. For edge/corner mounting this is measured around the corner, rather than directly between the holes
