Printables Generator

If you need to customise any of the SABT parts for your rig, you can do so here without needing to install or learn FreeCAD. Enter the desired measurements and a .STEP file will be generated and downloaded automatically.

Motor Bracket for Aluminium Profile Face

This is the bracket that attaches each tensioner motor to your aluminium profile.

It is designed to attached to the face of the aluminium profile and requires a minimum of two parallel T-slots

Source File: Motor Brackets/For Aluminium Profile Face (Parametric).FCStd

A .STEP file will be downloaded, which can be used in 3D printer slicer software

More parts from the project will be added here as they are updated to offer parametric input. If you find you cannot customise a part in a way that you need, please start a discussion on the GitHub repository.
