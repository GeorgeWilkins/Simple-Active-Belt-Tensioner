Motor Bracket for Aluminium Profile Face

This is the bracket that attaches each tensioner motor to your aluminium profile.

It is designed to attached to the face of the aluminium profile and requires a minimum of two parallel T-slots to bolt onto.

  • Cord Clearance Height: How far off the face of the aluminium profile the cord should exit the motor pulley (at least 50mm for motor drum clearance)
  • Hole Diameter: The size of the bolt holes (typically 8mm for M8)
  • Hole Spacing: The centre-to-centre distance between the mounting holes; equal to the distance between your profile slots
  • Bracket Width: How wide the bracket should be (typically equal to the profile's width)

Source File: Motor Brackets/For Aluminium Profile Face (Parametric).FCStd

A .STEP file will be downloaded, which can be used in 3D printer slicer software

Motor Bracket for Aluminium Profile Edge

This is the bracket that attaches each tensioner motor to your aluminium profile.

It is designed to attached to the edge of the aluminium profile and requires a minimum of two parallel T-slots to bolt onto.

  • Cord Clearance Height: How far diagonally from the edge of the aluminium profile the cord should exit the motor pulley (at least 50mm for motor drum clearance)
  • Hole Diameter: The size of the bolt holes (typically 8mm for M8)
  • Hole Inset: How far from the edge the mounting holes are inset (typically half the profile's slot/hole spacing)
  • Bracket Width: How wide the bracket legs should be (typically half or equal to the profile's width or depth)
